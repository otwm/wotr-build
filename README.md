# WotR Builds (패스파인더: 의인의 분노 빌드 저장소)

패스파인더: 의인의 분노(Pathfinder: Wrath of the Righteous)의 캐릭터 빌드 정보를 정리하고 관리하는 저장소입니다. 모든 빌드는 한국어와 영어 용어를 병기하여 게임 내외에서 참조하기 용이하도록 작성되었습니다.

## 🏹 동료 빌드 목록 (Companion Builds)

| 캐릭터 | 클래스 | 역할 | 링크 |
| :--- | :--- | :--- | :--- |
| **아루샬레 (Arueshalae)** | 에스피오나지 엑스퍼트 (Espionage Expert) | 원거리 물리 딜러 (DPS) | [상세 보기](./builds/party/arueshalae-ranger.md) |

## 🛠️ 사용 방법
1. 각 캐릭터의 링크를 클릭하여 상세 빌드 경로를 확인하세요.
2. 레벨업 시 선택해야 할 피트, 능력치, 신화 능력 등이 포함되어 있습니다.
3. 이 데이터는 나중에 프로그래밍을 통해 빌드 계산기나 데이터 분석에 활용될 수 있습니다.
